# 🔐 Honeycred Injector

Honeycred Injector is a deception-based cybersecurity tool designed to detect unauthorized access attempts using honeytokens (fake credentials). It helps identify potential intrusions by monitoring and logging the misuse of injected credentials.

---

## 🚀 Features
- Injects fake credentials (honeytokens) into systems
- Detects unauthorized access attempts
- Logs suspicious activity for analysis
- Helps track attacker behavior patterns

---

## 🛠️ Tech Stack
- Python
- Flask (for web interface)
- Linux Environment

---

## 📌 How It Works
1. Fake credentials are embedded into files or system locations.
2. These credentials appear real to attackers.
3. When an attacker uses them, the system captures and logs the activity.
4. Logs can be analyzed to detect intrusion attempts and patterns.
